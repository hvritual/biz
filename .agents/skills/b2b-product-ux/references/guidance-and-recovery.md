# 指导、操作影响与解决路径

这是 [九维 UX](humanized-ux.md) 中第6至9维的任务化用法，不另定义权限、价格、错误码或状态接口。

## 先分清用户遇到的问题

| 入口 | 对应义务 | 最小解释及出口 |
|---|---|---|
| 不知道如何开始或继续 | How-to Guidance | 目标、谁可操作、前提、步骤、观察结果、停止条件和接管 |
| 不知道操作会改变什么 | Operation Effect Transparency | 操作前的真实影响；操作后的实际结果与尚未完成部分 |
| 系统操作失败/结果未知 | Error Recoverability | 失败在哪、已知/未知状态、保留输入及原操作标识、安全恢复 |
| 系统正常但业务仍有问题 | Problem Resolution Guidance | 事实、替代解释、核实、处置、责任人、接管和解决条件 |

四者可以复用同一交互区域，但不能把工单创建、请求受理、设备上线和服务恢复混为一谈。

## 指导强度

已知用户可完成的简单任务采用就地一句话；非熟悉步骤按需展开；复杂或不安全事项进入专业接管。熟练用户可跳过说明，但不能跳过必要授权或危险操作确认。关键费用、影响范围、风险和不确定结果常驻展示，不依赖 hover 或自动消失 toast。图片须有文字替代，帮助可键盘访问，关闭后恢复任务焦点和草稿。

设备指引必须绑定审核来源、机型/版本、适用条件和有效性。资料缺失时只提供事实采集和真实接管出口；不编造错误码、拆修、清洁或复位步骤，不填未经证实的等待时间。接管时传递对象、现象、时间、已做核实、未决项，不传递用户无权查看的数据。

## 操作前后

操作前核对对象、作用域、版本、当前→目标差异、生效方式、费用/额度/权限等适用副作用及可逆性。预览过期或对象变化要重新确认。字段为未知不显示0；没有定价契约不计算升级差价。

操作后区分受理、排队、执行、部分完成、最终确认和未知。展示对应操作标识和真实可达的结果入口。没有权威回读时保留“不确定”，不能用界面刷新模拟成功。取消弹窗通常只是退出编辑，不能声称撤销已提交操作。

## 失败分流

| 事实 | 合理处理 | 禁止处理 |
|---|---|---|
| 输入校验失败 | 字段旁解释并保留输入 | 清空整个表单 |
| 无权限/能力未开通 | 解释获准范围内的原因，链接真实申请路径 | 换接口或使用演示身份 |
| 版本冲突 | 显示新版本与原草稿差异，重新确认 | 静默覆盖 |
| 写请求超时 | 先查询原操作状态；仅按真实幂等规则重试 | 默认未执行，换ID重新提交 |
| 部分成功 | 保留逐项状态与失败原因，验证重试范围 | 全部标失败或全部重做 |
| 业务未恢复 | 按解决条件继续核实或接管 | 用系统调用成功关闭问题 |

## 证据边界

文本存在仅是结构证据；浏览器验证可达性、焦点及状态；真实 API/现场确认验证结果；真人任务验证是否理解并能完成。信息/行动耗时目标按任务设定，无样本不写达标。结果与接管规则填回 [UX Contract](../UX-CONTRACT.md)；审核来源和实际证据缺失时保持 not_verified。
