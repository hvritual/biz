# Menu IA V2

## 目标

将前台导航从“页面堆叠”收敛为“一级业务域 → 二级分组 → 功能入口 → 快捷操作”，避免后续新增功能继续扩散一级菜单或把样例实体绑定到全局导航。

## 一级业务域

一级 Rail 固定为：

- 工作台
- 客户经营
- 租赁运营
- 设备运营
- 经营管理
- 企业中心
- 平台管理
- 系统设置

新增功能默认不得新增一级域，除非其业务对象、权限边界和生命周期无法归入现有领域。

## 二级信息架构

### 客户经营

- 客户管理：客户总览、联系人与协作、客户共享
- 客户协同：客户事项、客户风险
- 客户成功：经营计划、自动化规则、执行记录、流程与服务时限、经营结果

客户工作区属于具体客户上下文，只能从客户集合页或业务上下文进入，不作为全局菜单入口。

### 租赁运营

- 投放与资产：点位租赁、合同与续约
- 计费与结算：计费规则与共享组、租赁对账、回款跟进
- 履约与服务：投放交付、服务恢复验证、退租回收

没有独立集合页的租赁流程不得用 `CS-*` 等样例事项冒充全局功能入口。正式页面未接入时显示“待接入”。

### 设备运营

- 设备资产：设备管理
- 设备配置：饮品配置
- 远程运维：远程运维
- 服务维护：故障工单

饮品/配方属于设备能力与配置域，不归入经营管理。

### 经营管理

- 交易管理：订单管理
- 经营分析：数据分析

后续新增出杯、收入、物料、利润等经营分析能力时，应继续进入经营管理，不新增一级菜单。

## 治理规则

1. 一级菜单表达稳定业务域，不表达页面或动作。
2. 二级分组只用于视觉和信息架构，不新增可折叠第三级箭头导航。
3. 全局菜单不得绑定 `CUS-*`、`CS-*`、`SH-*` 等具体样例实体。
4. 没有正式集合页的能力必须标记待接入，不得通过样例详情页伪装成功能入口。
5. 快捷操作必须指向可解释的集合页或创建动作，不得绑定固定业务对象。
6. `web/ui-contracts.json` 是导航 IA 的机器可读契约；`check-ui-contracts.mjs` 与导航单测负责阻断回归。
