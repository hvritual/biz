# Menu IA V2

> 当前状态：与 `web/src/router/navigation.ts` / `customerNavigation.ts` 对齐  
> 复核基线：`main@d9ad0e068a89ac37bbb02ba4fdf59f371f80c267`

## 1. 目标

将前台导航固定为“一级业务域 → 二级分组 → 功能入口 → 快捷操作”，避免后续新增功能继续扩散一级菜单、绑定样例实体，或让平台级能力混入租户设置。

## 2. 一级业务域

一级 Rail 固定为：

1. 工作台
2. 客户经营
3. 租赁运营
4. 设备运营
5. 经营管理
6. 企业中心
7. 平台管理
8. 系统设置

新增功能默认不得新增一级域，除非业务对象、权限边界和生命周期无法归入现有领域。

## 3. 二级信息架构

### 3.1 客户经营

- **客户管理**：客户总览、联系人与协作、客户共享
- **客户协同**：客户事项、客户风险
- **客户成功**：经营计划、自动化规则、执行记录、流程与服务时限、经营结果

客户工作区属于具体客户上下文，只能从客户集合页或业务上下文进入，不作为全局菜单入口。

### 3.2 租赁运营

- **投放与资产**：点位租赁、合同与续约
- **计费与结算**：计费规则与共享组、租赁对账、回款跟进
- **履约与服务**：投放交付、服务恢复验证、退租回收

没有独立集合页的租赁流程不得用 `CS-*` 等样例事项冒充全局功能入口。正式页面未接入时显示“待接入”。

### 3.3 设备运营

- **设备资产**：设备管理
- **设备配置**：饮品配置
- **远程运维**：远程运维
- **服务维护**：故障工单

饮品/配方属于设备能力与配置域，不归入经营管理。

### 3.4 经营管理

- **交易管理**：订单管理
- **经营分析**：数据分析

后续新增出杯、收入、物料、利润等经营分析能力时，继续进入经营管理，不新增一级菜单。

### 3.5 企业中心

当前固定六个入口：

- 成员管理
- 角色权限
- 组织架构
- 套餐额度
- 企业信息
- 操作日志

快捷操作：

- 新增成员
- 邀请成员
- 新建角色
- 调整套餐
- 编辑企业信息
- 查看操作日志

企业中心只管理**当前租户自身**，不得承担平台级租户、全局套餐或全局权益治理。

### 3.6 平台管理

当前平台管理已经形成显式分组：

- **总览**：平台总览
- **租户生命周期**：租户管理、租户订阅、套餐变更、到期与宽限
- **产品与定价**：模块目录、商业功能、套餐版本、增购项
- **权益与授权**：租户权益、授权诊断、额度管理、专项授权
- **计量与治理**：用量计费、商业审计

快捷操作：

- 打开租户管理
- 创建或发布套餐
- 调整租户权益
- 查看用量计费

平台管理回答的是“平台允许哪些租户使用哪些商业能力，以及这些能力如何定价、授权、计量和治理”。

其中商业功能、订阅、变更、到期、授权诊断、额度、专项授权、用量计费、商业审计等页面当前存在统一 CoffeeLink Preview 界面；在服务端契约正式接入前，不得把 Preview 菜单入口解释为生产写能力已经完成。

### 3.7 系统设置

- 基础设置
- 安全设置
- 通知设置
- 接口与集成
- 数据字典

快捷操作优先指向基础、安全、通知、接口与集成等已有设置页，不制造点击即执行的危险操作。

## 4. 当前导航交互事实

桌面端有二级内容的一级域当前支持：

- hover 预览打开；
- click 切换打开/关闭；
- Esc / 遮罩点击 / 关闭按钮关闭；
- 二级入口导航后关闭 ModulePanel。

ModulePanel 是覆盖层，不允许推挤正文。当前 CoffeeLink 使用 18% scrim，并在展开时使正文不可交互。

## 5. 治理规则

1. 一级菜单表达稳定业务域，不表达页面或动作。
2. 二级分组只用于视觉与信息架构，不新增可折叠第三级箭头导航。
3. 全局菜单不得绑定 `CUS-*`、`CS-*`、`SH-*` 等具体样例实体。
4. 没有正式集合页的能力必须标记待接入，不得通过样例详情页伪装成功能入口。
5. 快捷操作必须指向可解释的集合页、表单或创建流程，不得绑定固定业务对象。
6. 平台管理、企业中心、系统设置必须保持不同权限与数据作用域。
7. `web/ui-contracts.json` 是导航 IA 的机器可读契约；`check-ui-contracts.mjs` 与导航单测负责阻断回归。
8. `navigation.ts` 或 `customerNavigation.ts` 发生 IA 变化时，必须同步本文件和 CoffeeLink 当前 UI 设计规范。
