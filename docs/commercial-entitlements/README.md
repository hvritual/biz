# 多租户商业权益实施计划

版本：1.0；制定日期：2026-09-09。

## 目标与交付边界

将已讨论的“多租户功能模块、套餐与动态权益管理方案”落实为 **8 条实施路线、26 个独立任务**。目标是平台人员动态配置模块、套餐与租户例外授权，租户按套餐自动开通、切换功能，后端统一执行限制，Vue 展示可信结果。

本次交付只有 docs 文档、机器可读任务台账及文档检查器；**没有实现商业权益业务、没有合并现有前端 PR、没有执行产品验收，也没有修改 Yunka 框架**。计划中的目标接口、表、测试均不是已存在能力。

## 执行入口

从 **CE-01** 开始。每次只领取一个已满足硬依赖的任务；一任务一分支／提交单元、一份执行回执、独立验证后集成 main。CE-11 只处理前端基线，不授权顺带合并其他业务分支。

运行文档检查（从仓库根目录）：

```sh
python3 docs/commercial-entitlements/tools/check_plan.py
```

检查通过只能证明本计划结构自洽，不能证明产品已经实现。任务初始状态均为 `PLANNED`；检查器按依赖计算可领取任务，不在多份 Markdown 中手工维护进度。未来回执使用 [执行约定](04-execution-contract.md) 指定的 evidence 目录。
