## 反例与故障验证

真实运行探针观察到：

```text
成功：authorize → entitlement → scope → begin → root → child → commit → close
child 失败：authorize → entitlement → scope → begin → root → child → rollback → close
Guard 拒绝或返回 nil：authorize → entitlement，未开始根事务
IAM 拒绝：authorize，未运行 Guard 或 Application
未声明 child：authorize → entitlement → scope → begin → root → rollback → close
嵌套 root：同样拒绝并回滚；未启动第二根事务
无根 child：拒绝，业务回调未执行
```

探针的记录型 UoW、内存幂等存储是 test-only 观察器，不冒充 MySQL 持久性验证；真实数据库另通过 TestB125TenantCreateBootstrapsOwnerInOneRootUoW 和 TestB125ChildFailureRollsBackTenantAndMemberAndAllowsIdempotentRetry，后者用数据库触发器制造 child 错误并验证根回滚及重试。

闭环检查器使用临时真实 Git 仓库验证：完整样例接受；仅 VERIFYING、零测试、失败退出码、缺少证据定位、验证 SHA 不一致、不存在提交、未集成 main 的提交均被拒绝。这些是检查器测试，不是商业产品用例。
