## 风险与回滚

缓存只能优化版本化派生数据，每次仍检查权威状态；可通过 `DisableEntitlementCache=true` 关闭缓存，但不能关闭权益限制。损坏快照须保留来源与历史，在新版本上重建，不能回拨来源/快照版本。

商业准入在事务内取得屏障并检查数据库时间时线性化；此前已准入的事务可在到期后提交。全局目录修改可能阻塞商业写，同租户视图准备存在短暂串行化。生产负载、生产迁移与生产回滚演练未执行。

发布先应用所属目录与权益新增 SQL 迁移，再启用新二进制。已启用租户不得回退到没有并发屏障的旧二进制来“恢复可用”；应关闭缓存、使用已验证受限版本或暂停相关入口，不删除审计或恢复免费授权。
