# CE-12 执行回执

日期：2026-09-12（Asia/Taipei；对应 GitHub Actions 主要执行时间为 2026-09-11 UTC）。此回执只确认 CE-12“平台／租户可信会话与切换契约”已完成，不代表生产部署、支付、真实 IoT 长任务、存量迁移或后续前端商业管理任务已经完成。

## 范围与结果

CE-12 原阻塞项已经由真实可验证的 Web 身份实现解除：Biz 现在提供第一方 OIDC Provider、Authorization Code + PKCE S256、服务端 BFF/Session 边界，以及从浏览器身份到租户 IAM/商业权益的可信执行链。浏览器不持有平台 API Key，也不接收 OAuth Access/Refresh Token；浏览器提交的租户或 Principal 信息不能直接成为服务端可信身份。

本轮最终信任链为：

`OIDC Identity -> Biz User -> Tenant Membership -> Role/IAM -> Commercial Entitlement -> Business Operation`

租户切换由服务端校验 membership 后更新服务端 Session；Web Session 的认证来源在运行时显式保留为 `web-session`，不伪装为 API-key。

## 已交付能力

- 第一方 OIDC Provider：`cmd/biz-idp`，独立运行并使用现有 Biz 用户／成员权威。
- Authorization Code + PKCE S256、state、nonce、精确 client/redirect 校验。
- RS256 ID Token 与 JWKS；活动签名钥匙和上一把验证钥匙并存，支持轮换重叠窗口。
- 浏览器只接收 HttpOnly 服务端 Session Cookie；OAuth Provider Token 不返回浏览器。
- OIDC Identity 绑定既有 Biz User；租户 membership、role、IAM 与 entitlement 仍由 Biz 内部事实源决定。
- 服务端租户切换；伪造 header 不能选择可信 Tenant 或 Platform Principal。
- PBKDF2-SHA256 本地凭据，仅附着到现有有效用户。
- 持久化登录节流与哈希登录审计；凭据失败返回通用错误，避免账号枚举。
- 凭据 rotate/disable 与现有 Web Session 撤销在同一 MySQL 事务内完成。
- 精确 post-logout redirect 校验；HTTPS 部署下 Secure Cookie 配置 fail-closed。
- 显式 MySQL migration：`0002_ce12_first_party_identity.sql`。
- 凭据管理 CLI：`cmd/biz-idp-credential`。
- Tenant-facing operation contracts 显式允许 `api-key` 与 `web-session`；框架侧 `AUTHENTICATION_WEB_SESSION` provenance 由兼容 Yunka 基线提供。
