## 范围与结果

## 反例与故障验证

真实浏览器和后端资格链不仅验证成功路径，也验证以下拒绝／撤销语义：

- 浏览器伪造 tenant/principal header 不能改变可信服务端 Tenant 或 Principal；
- 真实登录后，IAM deny 必须阻断业务操作；
- IAM 允许但 commercial entitlement deny 时仍必须阻断；
- 只有 IAM 与 entitlement 同时允许时业务路径才成功；
- logout 后原 Session 不能复用；
- credential rotate/disable 会撤销既有 Web Session，避免凭据变更后旧会话继续获得权威；
- 无效 active tenant 不会破坏身份 Session 本身，但不能继续获得该 tenant 的运行权限；
- IdP signing key rotation 使用不同 `kid` 的当前／上一把公钥验证重叠窗口，输出 `CE12_IDP_KEY_ROLLOVER=PASS`；
- Secure Cookie 在要求 HTTPS 的部署配置下 fail-closed，不以降级不安全 Cookie 绕过配置错误。

这些反例来自 CE-12 qualification 与 browser E2E 已执行场景；本回执没有把未执行的真实生产故障恢复或生产数据回滚描述为已验证。
