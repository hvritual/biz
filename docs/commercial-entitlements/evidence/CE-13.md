## 反例与故障验证

- 平台浏览器会话为 platform actor，带 platform_subject，active_tenant_id 为空。
- 租户会话直接进入平台 URL/API 被拒绝，不能用 header 提升身份。
- 缺少 CSRF 的平台写操作被拒绝；浏览器没有 API key。
- 套餐写路径含稳定 Idempotency-Key；平台 lifecycle 用例覆盖草稿、CAS、发布、权益来源、订阅预览、确认和回读。
- 异常 #89 的必填幂等键和 #90 的 409 冲突状态在实际 main 验收前已纳入候选修复和主线测试。

## 风险与回滚

代理/回调 origin、cookie/CSRF、跨标签会话变化以及 CAS 状态映射仍是主要兼容风险。发现异常时先停止本地 Web/Biz/IdP 进程和新平台写入口，保留订阅、套餐、权益来源、回执和审计事实；用新套餐版本、订阅变更或显式补偿前向修正。不得删除租户、回拨权益/套餐版本、关闭 Guard 或暴露浏览器 API key。
