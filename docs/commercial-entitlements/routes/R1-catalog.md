# R1 能力目录与 Operation 映射

独立产物：可查询、可校验、可管理的已部署产品能力目录。无需等待订阅、支付或 Vue；通过真实后台 API 与契约检查验收。上游无业务依赖，向 R2/R3/R6 提供 CatalogContract。

通用执行规则见 [任务执行约定](../04-execution-contract.md)，状态以 [台账](../tasks.json) 为准。下列测试标识均为待创建要求，不表示现有测试。

## CE-01 固定基线、领域契约与运行时探针

依赖：无
验收标识：TestCE01

**目标与输入**：读取最新 biz main、框架锁定、前端候选与目录约束；把上一轮运行时假设变成有代码证据的实施边界。

**交付要求**：记录后端／框架／前端固定 SHA；验证 generated contracts、Application owner 封装、Guard 扩展点、Guard／事务时序和 child 执行路径；冻结 commercial 契约命名、稳定 ID、错误类型、额度和时间表示。形成最小可运行探针与 ADR，明确哪些接口来自现有框架、哪些是拟新增业务接口。登记既有真实 Operation 及缺失业务输出面；不以 UI 文案推断后端能力。

**改动边界**：允许商业领域设计文档、`internal/architecture/` 下只读结构测试或独立探针、必要契约草案；不修改生产授权语义，不生成假业务实现，不升级框架，不合并前端 PR。探针不能含真实平台密钥。

**验收**：TestCE01 至少证明锁定来源可解析、生成路径可复现、Guard/child/根事务事实与记录一致；给出实际命令、非零测试数和固定路径证据。若扩展点不支持，记录真实最小重现并按执行约定阻塞，不编造框架 API。独立交付后不改变现有业务行为。

**回滚**：撤回新增探针及 ADR 的错误部分，不回退既有框架；契约修改要保留修订说明。交付为单独提交及 CE-01 回执。

## CE-02 模块目录、技术状态与依赖管理

依赖：CE-01
验收标识：TestCE02

**目标与输入**：利用 CE-01 锁定的能力标识和平台主体模型，让管理员管理真实已部署能力的商业属性。

**交付要求**：实现 module.proto、ModuleCatalog 应用、持久化 schema／显式迁移及平台 CRUD；区分技术未就绪／就绪／停用与商业可售／停售。能力、支持额度、字段策略 schema 和依赖由代码声明；管理员编辑名称、分类、销售范围，不能随意创造 Operation。发布或更改依赖时检测缺失项与环；引用中的模块禁止硬删除，历史编码不可改名复用。写操作使用版本及根幂等，审计操作者、前后差异和原因。

**改动边界**：允许 `contracts/proto/commercial/v1/module.proto`、所属 application/domain/persistence、模块及 runtime 装配和生成产物；不动原有租户／角色语义，不卸载租户对应的 Yunka module，不实现价格或支付。

**验收**：真实 MySQL 上执行创建／修改／停售；租户身份调用平台 API 被拒绝；无技术实现、依赖环、过期版本、重复请求和被引用删除均有正确结果。停售保留已有状态，不混成安全停用。REST/gRPC 接口注册与生成检查通过。

**回滚**：先撤出新增管理入口或回退商业配置版本；不硬删有引用目录数据。迁移保持向前兼容，现有 Access/DeviceOps 不受影响。

## CE-03 商业能力映射与入口覆盖门禁

依赖：CE-02
验收标识：TestCE03

**目标与输入**：从既有 PB 生成的 Operation 清单与模块目录形成唯一受控映射，避免页面、Guard 和数据库各自维护一套功能编码。

**交付要求**：建立版本化 Operation→Capability 声明，显式区分租户商业业务、平台管理、恢复入口和基础能力豁免。记录组合根入口与声明 child 依赖；条件分支能力不能被错误地全量收敛或遗漏。生成／派生前端可用稳定类型或机器清单；检查所有被引用 ID 存在、映射无重复／冲突、豁免有理由。新增未分类租户业务入口时检查必须失败。

**改动边界**：允许单一声明文件、派生生成器／检查器、架构测试及相关构建目标；不手改 PB 生成代码，不把菜单 URL 当安全规则，不先扩展 Yunka DSL。此任务只闭合声明与覆盖，不冒充已完成运行时授权。

**验收**：正向全目录检查通过；反向添加不存在 ID、重复映射、未分类新 RPC、缺失 child 能力和无理由豁免，分别触发有定位信息的失败。能从 DeviceOps 的一个真实 Operation 追溯到能力、模块及消费者类型。记录新增命令并接入已有本地检查路径。

**回滚**：回退映射版本并重新派生产物；已经发布的能力编码不可重用。运行时接入由 CE-05 独立完成。
