# R2 生效权益与运行时控制

独立产物：不用套餐或支付，平台专项授权即可控制真实租户 API，并能解释允许／拒绝来源。向 R3/R4/R6 提供 EntitlementDecision 与版本化读取契约。

通用规则见 [执行约定](../04-execution-contract.md)。本路线不替换 IAM，不在每个 Application 重做身份授权。

## CE-04 专项授权与统一权益解析

依赖：CE-02
验收标识：TestCE04

**目标与输入**：基于模块目录，完成第一条可执行的“平台授权→租户有效能力”纵向切片。

**交付要求**：实现 entitlement.proto、专项开通／明确禁用／额度增量或替换、起止时间、原因、操作者及版本；实现确定性权益解析器和来源解释查询。安全／技术拒绝与租户明确拒绝优先；未知能力默认不可用；依赖缺失不能仅靠开通标记绕过。布尔、数量、字段动作分别合并，区分零与无限。为套餐／附加包保留类型化来源接口，但本任务只用真实专项授权持久化证明，不接假套餐源。基础恢复入口使用 CE-03 后续确认的显式策略，不给所有业务隐式免费权限。

**改动边界**：商业权益所属应用、领域、持久化和生成契约；不改成员角色，不让管理员直接改派生快照，不实现运行时 Guard。事务与审计通过现有执行模型。

**验收**：A 开通、B 无授权得到不同结果；开通＋禁用、授权过期、未来生效、依赖缺失、非法无限值、额度替换与增量冲突均有确定结果；真实 DB 重启后配置仍在。并发修改使用版本冲突，重复请求不重复生成赠送额度。查询显示每项来源与最终限制原因。

**回滚**：撤销专项授权形成新版本，不删除审计；回滚解析变更前先验证历史来源仍可重算。

## CE-05 根入口与 child 路径的服务端权益限制

依赖：CE-03、CE-04
验收标识：TestCE05

**目标与输入**：将已校验映射与统一解析器接入现有 GrantAuthorizer／ExecutionSecurity／OperationGuard 边界，用真实 DeviceOps 验证。

**交付要求**：组合商业能力 Guard 和原有 DataScope Guard，不替换原有认证／成员授权。根入口明确所需能力；条件 child 分支在实际执行位置验证必要商业不变量，不要求所有分支的未用能力，也不能绕过检查。未分类入口不默认开放。统一错误映射及审计关联；平台管理主体访问租户资源仍按声明的操作授权，不凭空获得全租户业务访问权。

**改动边界**：商业策略适配、`internal/bizruntime/` 装配、必要真实用例的类型化商业校验与集成测试；不增加第二套 Executor，不跨域访问 Repository，不在 Guard 扣额度，不手工修改 generated policy。

**验收**：REST、gRPC、组合根、条件 child、直接入口均验证 A/B 租户差异；租户已购但成员无角色权限／无数据范围仍拒绝；租户 owner 未购买同样拒绝。停用技术能力即时影响新请求。测试至少覆盖现有 device.list／create／transfer 对应真实路径及可用内部组合，不只测解析器函数。

**回滚**：试点前可以移除未启用的接入；已启用租户必须维持限制，可退回先前已验证的策略版本或关闭相关入口，不能全放行。记录回滚对既有业务可用性的影响。

## CE-06 权益快照、时间边界、撤权与并发屏障

依赖：CE-05
验收标识：TestCE06

**目标与输入**：使服务端在并发变更、缓存过期与通知失败时仍能正确限制。为下游订阅变更与额度预占提供统一当前版本和有效时间契约。

**交付要求**：持久化派生权益快照及来源版本，原子切换当前版本；返回 entitlement_version、permission_version 关联、valid_until 和 next_transition_at。缓存只能存版本化派生值，不作为可编辑真相。敏感写请求在根事务内验证当前权益，通过明确锁／版本屏障与撤权串行化；定义全局禁用、租户撤权、订阅切换和业务写的固定锁顺序，验证死锁重试策略。根 Guard 外的判断不承担额度／关键写原子保证。过期或预约边界处不能沿用旧允许，必要时重算或拒绝。提供结构化“当前有效权益＋原因”查询。

**改动边界**：权益应用、持久化、缓存适配、typed 校验操作及涉及严格副作用的调用点；不把缓存不可用解释成免费授权，不回拨版本，不要求所有只读查询持全局写锁。

**验收**：撤权提交后启动的新请求不能获得旧允许；并发关键写与撤权符合定义的串行顺序；覆盖全局禁用与租户例外撤销。缓存旧值、版本丢失、通知未发、DB 故障、跨实例竞争、授权时间边界都安全失败或正确重算。已有成员撤权语义不退化。记录锁竞争代价而非无依据承诺性能。

**回滚**：关闭缓存优化并回到权威读取；必要时使用新版本重建快照。禁止恢复旧快照覆盖新审计或删除当前限制；保留可重建来源。
