# R4 可信身份、平台管理与租户运行控制台

独立产物：基于当前 Vue 工程接入真实身份和商业能力。CE-11/12 可在订阅未完成时独立交付；后续页面只消费已交付 API。

纯前端任务遵守 web/AGENTS.md：不调整后端授权以迁就 UI，不把 preview 成功当生产成功。技术、视觉与数据状态边界见 [基线](../00-baseline-and-decisions.md)。

## CE-11 Vue 前端基线选择与受控集成

依赖：CE-01
验收标识：TestCE11

**目标与输入**：以实际 PR #19／已确认设计的固定提交作为候选，解决 main 无对应正式前端基线的问题。

**交付要求**：核验候选 HEAD 与其他相关 UI 分支，记录选定来源和差异，保留已接受页面／样式／tokens。只集成必要 web 工程与其校验配置，保留最新 main 的后端。确认 Node、lockfile、API 与 preview 模式隔离、组件边界和现有脚本；保留 Vue 3/TS/Vite/Router/Pinia/Lucide。记录 480px 双列浮层、无子菜单箭头、快捷操作逐行、不推动 main 布局以及响应式检查。

**改动边界**：web 与确实必需的前端工作流／文档；禁止整体合并含旧 Go 代码的分支，不引入 React／新 UI 框架，不触及套餐授权业务，不顺带实现组织等外围域。

**验收**：npm ci、check、test:e2e 非零测试通过；提供 1366×768、1440×900、390×844 真实运行截图；旧 Go 业务树未因集成被替换。无法接受的候选问题记录阻塞而非静默换模板。此任务通过仅表示前端基础可用。

**回滚**：撤回本任务新增的 web 集成，不回退后端 main；保留来源证据和已确认设计说明。

## CE-12 平台／租户可信会话与切换契约

依赖：CE-01
验收标识：TestCE12

**目标与输入**：复用现有 Access 身份模型，交付真实 SessionContext，使页面身份和租户不由 localStorage 或任意 header 决定。

**交付要求**：选择并记录一条可验证的 Web 身份接入方式，明确登录凭证来源、服务器验证、会话过期／退出、成员与租户停用后的失效。平台主体保持 tenantless 权限边界；租户切换需服务端验证 Membership 和有效状态，返回范围明确的可信上下文。采用 cookie 时补 CSRF／同站策略；采用其他令牌时明确存储与刷新安全。提供会话查询、允许切换租户列表与切换接口及错误契约。不得将平台 API key 暴露给浏览器或用假超级租户代替平台身份。

**改动边界**：必要的 Access 会话／认证适配契约、边界应用和运行时装配、测试；不重建用户／角色系统，不顺带做社交登录、密码营销流程。身份源不具备时任务 BLOCKED，不能用 demo 主体过关。

**验收**：真实登录路径可得到受限上下文；伪造 tenant 值／平台标志无效；非成员、停用成员、停用租户不可切入；过期／退出后不可复用会话；普通 owner 不能获得平台权限；不同租户访问隔离。权限撤销不依赖长期令牌内过期权限声明。

**回滚**：撤销新会话并禁用新入口，保留现有已验证认证路径；禁止因回退放宽根认证。

## CE-13 平台模块、套餐与租户权益管理页面

依赖：CE-06、CE-07、CE-09、CE-11、CE-12
验收标识：TestCE13

**目标与输入**：将 R1/R2/R3 真接口接入平台管理上下文，管理员可完成配置、发布、专项调整与已支持的订阅变更。

**交付要求**：模块列表／详情／依赖与销售状态；套餐草稿／不可变版本／能力矩阵／字段模板／额度／发布停售；租户权益显示“套餐继承、专项调整、最终有效”及来源。变更预览后提交，显示 change_id、当前阶段、版本冲突和真实失败，不在按钮点击时直接显示已生效。前端请求只进入 services；权限和能力使用稳定代码；平台与租户导航清楚分离。过期、未购、技术停用、无角色权、错误与空数据分别显示。

**改动边界**：web 的平台商业 feature、services、route/meta、类型和测试；不修改 Go 规则、不手填 mock 权益、不合并别的未完成页面。接口不足记录对应后端任务问题。

**验收**：通过真实 API 完成发布套餐、给一个租户开通／禁用、查看来源、预览并执行免费／有权人工变更。租户身份直接访问平台 URL 及 API 均无权；版本冲突可重新读取，不静默覆盖。保留布局和键盘验收截图。

**回滚**：关闭新增管理路由或恢复前端版本，不删除后端商业配置；在途操作按 change_id 回读后处理。

## CE-14 租户权益视图、导航与切换隔离

依赖：CE-06、CE-08、CE-11、CE-12
验收标识：TestCE14

**目标与输入**：租户成员根据服务端会话、权益与成员权限看到正确功能，不再根据中文套餐名计算权限／额度。

**交付要求**：真实会话与权益 Pinia 状态，静态受控路由 meta 声明能力、单一菜单／子菜单／快捷操作过滤、深链接守卫及按钮／字段呈现。当前套餐与限制读取后端；CE-19 未接入实际用量前明确标注未接入，不能伪造零用量。切换租户取消旧请求、清理旧列表／选中项／对话框、隔离缓存并防迟到响应；使用请求代际或同等机制。权益变化时重新拉取；当前页面失权说明原因并退出受限操作。通知尚未交付可先使用焦点重校验与受控轮询，不依赖前端刷新保障后端权限。

**改动边界**：web 的会话／权益 services、状态、路由／布局消费和套餐展示；不动态执行服务器下发组件路径、不自动改用户角色、不修改后端授权。

**验收**：A/B 租户不同模块、同租户不同角色、直接 URL、页面未刷新后台撤权、切换时旧响应迟到、多标签状态变化及接口失败均正确呈现。旧数据不可闪回覆盖；正式 API 失败无 demo fallback。新增高级能力不自动赋给普通成员。

**回滚**：退回先前已验证 UI，保持服务端限制；未确认上下文时不展示旧租户数据。所有缓存状态可安全清空重建。
