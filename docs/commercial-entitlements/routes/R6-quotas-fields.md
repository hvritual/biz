# R6 存量额度与字段权益

独立产物：对已存在的真实业务入口执行资源额度与字段保护，不依赖支付供应商、完整客户域或新的报表业务。

本路线不将普通缓存统计用于硬额度判定，不把所有资源都抽象成无语义的一个计数器。任务状态见 [台账](../tasks.json)。

## CE-18 原子额度核心、预占与释放

依赖：CE-06
验收标识：TestCE18

**目标与输入**：利用当前权威权益版本，在根 UoW 内控制 used＋reserved＋requested 不超过有效 limit。

**交付要求**：实现 quota.proto、额度定义、计量口径、当前使用／预占记录及幂等关联；支持原子 Reserve/Commit/Release 或等价的类型化业务操作，正确处理失败回滚、重复释放和过期预占。限制来源包括当前权益与未来附加包；区分零、无限与未知。固定与 CE-06 撤权屏障兼容的锁顺序；额度减少与占用不能各自读旧值后同时放行。返回用量更新时间和状态，查询错误不返回零。提供预占过期清理／对账入口，注册可靠运行组件或明确由谁调用，不依赖页面访问清理。

**改动边界**：额度所属领域、应用、schema／显式迁移、typed ports 和运行组件；不统计跨应用私有表、不在入口 Guard 扣数、不引入周期 API 用量计费，不先上分布式 Redis 锁替代 DB 事务证明。

**验收**：真实 MySQL 的并发最后名额仅合法请求成功；业务回滚不占用；同幂等键不重复扣数；重复释放不出现负数；预占到期、额度降低、无限切换、事务重试、DB 故障均结果确定。读请求和减量操作不因超额无差别阻断。

**回滚**：停止新占用入口并保留账本；对账后释放有证据的孤儿预占，禁止清空全部用量。schema 保持旧已验证业务可读。

## CE-19 成员与设备的真实额度接入

依赖：CE-09、CE-18
验收标识：TestCE19

**目标与输入**：在当前已有成员和设备生命周期中证明额度原子性，不只测试计数器接口。

**交付要求**：成员邀请预占、激活转已用、移除／取消／过期释放；停用未移除按既定口径继续占用。设备新增与删除正确占用／释放；现有同租户点位转移不能重复占用。通过声明的 child Operation 在相同根 UoW 中更新额度和业务记录。降级影响预览读取所属领域公开统计能力，最终变更与并发新增使用统一屏障；超额只限制净新增，保留存量。提供真实额度查询接入 CE-14 页面；批量操作明确全成或逐项结果语义，不允许通过 bulk 绕过。尚未存在的客户／跨租户设备转移仅列待接入，不伪造完成。

**改动边界**：现有成员／设备的最小契约和应用调用改动、商业额度适配、必要生成器产物、额度读取 services；不重构整个 Access/DeviceOps，不跨域访问 Repository，不破坏 owner 保护。

**验收**：邀请／取消／激活／停用／移除完整链路，device.create/delete 与真实组合路径；并发新增遇到降级、最后 owner 移除失败、重复提交、子操作失败均同时保证业务和计数正确。同点位转移额度不变化。前端用量等于权威查询，延迟和错误可识别。

**回滚**：暂停相关净新增，使用真实业务与额度账本对账修复；不删除超额成员／设备，不把 quota check 改成总是允许。

## CE-20 字段动作与所有真实输出面的服务端保护

依赖：CE-06、CE-07
验收标识：TestCE20

**目标与输入**：将套餐／专项字段策略落实为服务端行为。按 CE-01 清单选择真实已有 DTO 字段，保留必要身份／版本字段，不凭参考图新增业务字段。

**交付要求**：分别实现读取、写入及实际存在的导出动作策略；服务端投影／序列化不返回无权字段，写请求提交无权字段明确拒绝。强制脱敏是更高约束；权限与权益共同决定结果。检查单条、列表、批量、可用导出／报表、过滤／排序／聚合与日志等输出面，防止通过条件或派生值恢复受限字段。前端只消费策略呈现列／控件，不承担保密边界。不存在的导出下载功能列为未适用，未来入口由 CE-03 覆盖门禁阻止漏接，不能标为已经验收。

**改动边界**：商业字段策略、真实输出／输入适配边界、必要 PB 类型及对应前端字段呈现；不全局改写 JSON 编码器，不为证明覆盖新增不需要的导出产品。

**验收**：两个套餐／两个角色读取同一记录得到正确字段集合；直接请求、批量、过滤排序、失败信息和相关日志不能泄露；绕过前端提交受限字段失败且不发生写入。强制脱敏不因套餐升级放宽；未知字段策略拒绝发布。提供当前输出面清单及未适用项理由。

**回滚**：改用更保守的投影／拒绝规则或关闭新增输出入口；禁止返回全字段作为兼容 fallback。保留原始业务数据，不通过删数据实现权限回滚。
