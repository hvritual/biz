# R7 附加包、支付与 IoT 长任务扩展

独立产物：CE-21 扩展基础订阅组合；CE-22 和 CE-23 各自按真实外部条件接入，互不依赖。没有供应商或真实任务域时，保持 BLOCKED／PLANNED，不阻塞核心免费／人工确认订阅路线。

外部条件见 [基线](../00-baseline-and-decisions.md)；本路线不是提前选用某支付品牌或创造 OTA 产品的授权。

## CE-21 模块与额度附加包

依赖：CE-07、CE-09、CE-18
验收标识：TestCE21

**目标与输入**：在一个基础套餐上叠加多个真实、有期限的模块／额度来源，减少为特殊租户复制套餐。

**交付要求**：定义附加包不可变版本、模块／额度增量、可组合基础套餐、数量规则、重复购买策略、起止时间与取消规则。购买／配置通过 CE-09 同类变更与回执，接入统一解析器和额度来源；保留每项来源明细。附加包到期只移除自己的贡献，不能关闭其他有效来源；明确拒绝和强制限制始终优先。基础套餐切换前检查附加包兼容性，预览移除／保留／待处理结果。前后端显示基础套餐、附加包、专项调整与最终值。

**改动边界**：商业附加包 schema、版本与订阅用例、解析适配、必要管理／租户展示；不另建一套权益表让各页面自行合并，不要求先接支付。

**验收**：多个来源叠加、重复确认、独立到期、降级不兼容、无限与有限额度组合、套餐和专项拒绝冲突都符合定义；不能移除 A 附加包时错误关闭 B 的能力。额度减少后保留存量、限制净新增。服务端与前端来源解释一致。

**回滚**：停止新增购，按新变更撤销指定来源；保留其他来源、原购买及审计，不直接覆盖最终快照。

## CE-22 真实支付供应商适配与自动确认

依赖：CE-10、CE-15
外部条件：PAYMENT_PROVIDER_READY
验收标识：TestCE22

**目标与输入**：在供应商、商户沙箱与业务规则具备后，用可信付款事实推进已有开通流程；免费链路不依赖本任务。

**交付要求**：独立 PaymentProvider 适配、订单与 change_id 关联、服务端确定金额／币种／套餐版本及最小货币单位表示；验签及供应商规定的重放保护，核对商户／订单／金额／币种／状态。Inbox 幂等、乱序状态保护与主动查询对账；真实付款成功才推进开通。定义超时、支付取消、退款／部分退款／争议对订阅的明确业务策略，旧事件不得撤销较新订阅。平台凭据只由运行环境注入，不在 VITE 或代码中出现。支付跳转页只显示待核验状态。

**改动边界**：一个选定供应商适配、必要可信 webhook 入口和订阅事件消费、前端支付状态展示；不重造金融账务平台，不将外部 API 调用放在长 DB 事务内，不默认选 Stripe 或其他供应商。

**验收**：真实供应商沙箱完成付款／取消及支持的退款流程；无效签名、金额不符、重复／乱序事件、回调丢失、查询对账、支付成功但开通失败均正确处理。测试层可注入故障，但至少一条真实供应商往返证据不可由 mock 替代。源码与产物无凭据。

**回滚**：停新支付申请、保留回调核验与存量对账；已付款订单不得丢失，按明确退款或继续开通策略处理。不能仅撤前端就停止处理已发生付款。

## CE-23 真实 IoT 长任务的权益执行边界

依赖：CE-05、CE-10、CE-16
外部条件：REAL_IOT_JOB_READY
验收标识：TestCE23

**目标与输入**：在已有真实任务领域选一条有持久化队列／Worker／设备回执的操作链，避免“提交时有权限，执行时已到期”绕过。

**交付要求**：任务持久化 tenant、所需能力、提交权益版本、执行状态与来源；提交时检查、领取后产生副作用前再次验证当前权益，包含 scheduled/background/service principal 的可信租户绑定。排队未下发可停止／拒绝；已下发操作按具体设备协议安全收尾，必要回执和安全通信持续接收。明确外部副作用起点、重复指令去重、重启恢复、撤权与下发竞争的排序和不可逆部分。生产授权不能依赖任务载荷里客户端自报的 plan 或 tenant。

**改动边界**：选定真实任务域的最小执行边界适配、商业 typed 检查、回执关联及测试；不为了测试新造 OTA／参数管理整域，不中断基础设备通信，不通过清空队列假装所有任务已撤销。

**验收**：排队期间降级／到期／专项禁用，执行前拒绝；已下发后撤权，设备回执仍能闭环；多 Worker、重复回执、重启、服务主体越权和下发并发可复现。可用受控设备模拟，但后台任务、Worker、持久化与协议往返必须真实运行；缺失真实任务域则本任务不得 DONE。

**回滚**：停止新任务下发，保留结果接收与在途收尾；记录无法撤销的设备动作，不用盲目断网或丢弃回执回滚。
