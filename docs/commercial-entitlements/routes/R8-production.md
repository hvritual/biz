# R8 存量迁移、门禁与生产资格

独立产物：将已验证核心能力迁入存量环境，并证明代码、数据和运行版本一致。R8 不顺带实现缺失业务；发现缺口退回所属任务。

核心发布不要求 CE-22/23，但启用对应支付或设备能力时必须增加其条件资格。执行和证据格式见 [约定](../04-execution-contract.md)。

## CE-24 存量租户与套餐版本的分批迁移

依赖：CE-09、CE-16、CE-19、CE-20
外部条件：MIGRATION_DATA_READY
验收标识：TestCE24

**目标与输入**：用经确认的存量授权事实建立初始订阅，并支持老套餐版本分批迁到新版本；不采用前端演示额度作为真实数据。

**交付要求**：迁移清单、来源版本／摘要、按租户差异预览、规则冲突分类及人工决策记录。支持 dry-run、指定租户／批次、断点续跑、幂等、并发版本保护和每租户结果回执。转换套餐、例外、额度及字段时保留可解释来源；未知权益不自动授予无限或最高套餐。对照模式与强制启用范围显式记录；迁移不越过已有授权安全规则。新旧模型切换期间明确唯一写入方，避免双写漂移。提供更高版本的补偿迁移与停止条件。

**改动边界**：专用迁移命令／应用、必要兼容读取、清单和迁移文档；不批量删除现有租户／设备／成员，不无备份覆盖数据，不擅自操作生产环境。

**验收**：用确认的隔离迁移数据完成干跑→小批→中断→续跑→补偿；迁移途中有真实订阅变更时不覆盖较新结果；错误数据隔离，其他批次可继续或按明确策略停止。迁移前后权益、资源用量、字段与历史记录可对账，每租户有 receipt。

**回滚**：停止新批次，按已记录来源与当前版本发起补偿，不回拨全库快照覆盖新业务与审计。不可恢复项必须提前列入发布阻塞。

## CE-25 硬化检查、反向测试与全链路压力

依赖：CE-13、CE-14、CE-15、CE-17、CE-19、CE-20、CE-21
验收标识：TestCE25

**目标与输入**：把前述规则变成可重复失败／成功的工程门禁，验证完整核心而不是仅汇总各任务“通过”。

**交付要求**：整合 Operation 覆盖、模块依赖、发布版不可变、跨域依赖边界、禁止前端套餐名判权、API 模式禁止 demo fallback、租户状态隔离及生成一致性检查。新增真实反例样本，证明违规变更触发有定位信息的失败。完善 REST/gRPC/child/UI/并发/时间/故障矩阵和多实例压力；任务选择必须匹配非零测试数。性能预算在测试前结合环境／现有基线写明，记录 p50/p95/p99、吞吐、错误、DB/锁等待，不事后为通过而改门槛。扩展已启用时追加支付和设备任务验收，未启用必须标记未认证。

**改动边界**：脚本、测试、现有本地检查入口及仓库可用 CI；不要求购买分支保护能力，不降低现有 B12/owner/租户隔离门禁，不把缺失业务修复隐藏在测试任务里。框架缺口遵循独立记录流程。

**验收**：全部适用 AT 场景有实际执行证据；至少未映射新 RPC、越界 Repository 依赖、前端套餐名分支、同租户额度超发、迟到响应覆盖等反例真实被阻止。合法实现与原有 Access/DeviceOps 回归通过；输出最终 source SHA 与环境，不复用过期分支日志冒充主线结果。

**回滚**：检查器错误需保留最小反例修正规则，不能删除检查或空跑测试恢复绿色。暂停发布而不是回滚为无权限控制版本。

## CE-26 分批启用、可观测性与最终资格

依赖：CE-24、CE-25
外部条件：DEPLOYMENT_READY
验收标识：TestCE26

**目标与输入**：在已准备的部署环境证明迁移、服务版本、执行结果与 GitHub 主线一致，并完成可操作回滚演练。

**交付要求**：明确启用租户范围、停机／无停机迁移步骤、运行版本回读、健康检查、权限拒绝／额度冲突／开通失败／调度积压／快照漂移的监控与告警；业务审计可关联 actor、tenant、change_id、版本和任务。日志脱敏，指标不以无限 tenant_id 标签造成无界基数。依次对照、试点、小批扩容，设置停止与恢复条件。演练关闭新申请、恢复任务、补偿权益及保留在途安全回执；不能全局关闭 authz 作为回滚。分别签发 Production Core／Paid／IoT Job 范围，未完成的条件扩展不挂已就绪标记。

**改动边界**：已有部署配置、必要诊断与告警、发布／回滚手册和证据；不得未授权操作真实生产资产，不将运行密钥提交仓库，不借此重构框架或基础设施。

**验收**：在最终 main 的真实业务 SHA 对应构建上完成多实例租户隔离、套餐切换、调度恢复、额度／字段、迁移与回滚演练；平台页面、租户页面、查询 API、DB 版本和执行回执一致。记录未验证范围，部署前置条件未满足时不出生产通过结论。CE-22/23 仅在其真实证据齐全时纳入扩展资格。

**回滚**：按演练过的步骤暂停新变更、保留处理回执、恢复先前已验证代码或前向修正数据；数据／外部动作不可逆处明确补偿。回滚后再次执行受影响安全回归并记录最终版本。
