# CoffeeLink 国际化最小运行时

关联 #144。国际化是展示能力，不是身份、权限、路由或业务值的事实源。

## 当前交付范围

首批只支持 `zh-CN` 与 `en-US`，覆盖：

- 应用顶栏语言切换、一级导航，以及企业中心 / 平台管理 / 系统设置的二级导航与快捷操作；
- `/platform/tenants` 的标题、状态、筛选、表格、分页、生命周期确认及错误回退文案；
- `/enterprise/members` 的标题、统计、筛选、列表、分页、详情、成员写操作与批量确认；
- 上述页面依赖的 `AppPagination` 与 `EnterpriseSourceBanner`。

客户经营、租赁运营、设备运营及其它企业页面未在本切片内迁移。它们继续使用现有中文文案，不能因为应用已经存在语言开关就声明“整站国际化完成”。模块面板对这些未迁移业务域保留现有业务标签。

## 事实与状态边界

- `router` 的 path、module ID、domain ID、权限和服务端状态码均保持稳定；显示 label 由 locale 决定。
- 企业名、成员名、租户 ID、设备 ID、用户输入、服务端错误正文与其它实体事实不翻译。
- `localStorage['coffeelink.locale']` 仅是展示偏好，不是租户配置或权限来源。
- 未支持 locale 回退到 `zh-CN`；缺 key / 占位符漂移由测试失败，不静默把半套翻译当完成。
- 语言变化不重置查询、勾选、分页、当前路由或可信会话。

## 格式化

`web/src/i18n/index.ts` 是唯一格式化入口，基于标准 `Intl`：

- 数字、百分比、货币、单位根据 locale 格式化；货币格式化不会换算金额或选择币种。
- UTC 瞬时时间必须显式传入展示时区；`date-only` 使用 UTC 正午构造以避免跨时区日期漂移。
- 相对时间只改变呈现，不参与设备在线、租赁到期、结算或权限判断。
- 服务端返回未知/null 时，由业务组件先保留其真实“未知”语义，格式化器不把未知转换成 0。

## 门禁与证据

`npm run check:i18n` 仅扫描已迁移的 SFC，阻止新增硬编码中文可见文案；不会扫描测试 fixture、实体数据、日志和未迁移页面。Vitest 比对中英文 key 与 interpolation 参数，并覆盖时区/DST、date-only、货币、百分比和单位。

Playwright 证明：

1. 切换语言不改变 `/enterprise/members` 或 `/platform/tenants` 的路由身份；
2. 成员查看仍不等于勾选，关闭详情焦点返回原触发器；
3. 成员写操作的确认弹窗与 ARIA 名称同步切换；
4. 两个试点页面在 1366×768、1440×900、1536×1024、390×844 下的英文长文案没有页面级横向溢出。
