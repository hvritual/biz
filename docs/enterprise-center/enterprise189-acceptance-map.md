# Enterprise #189 US-001～045 Acceptance Evidence Map

This map is the acceptance index for #189. It does not replace the owning issue tests in `docs/enterprise-center/requirements-map.md`; it binds the forty-five UI stories to concrete entry/state/test/API/storage evidence used by the #189 full-runtime candidate.

## Evidence rules

- **REAL_BROWSER** means the test runs against the first-party IdP, BFF, Biz API and isolated MySQL in `.github/workflows/ce12-browser-e2e.yml`.
- **REAL_MYSQL** means an integration test uses the repository's real MySQL qualification path and authoritative persistence.
- **API_MODE_E2E** means the canonical UI contract test deliberately injects HTTP outcomes to prove a UI failure/recovery state; it is not evidence that the injected server failure originated from a production dependency.
- **CONTROLLED_FIXTURE** is restricted to qualification ingress where production intentionally exposes no event-fabrication endpoint. Downstream Notification Runtime, MySQL routing, BFF inbox and UI are real.
- External email/SMS provider sandbox qualification remains the separate #185/#192 release boundary. #189 does not relabel httptest/MemorySender/controlled ingress as a third-party provider PASS.
- Candidate SHA, workflow run/attempt, screenshots and performance receipt are runtime evidence and are recorded in the PR/CI receipt for the exact candidate; this source map intentionally does not hard-code a mutable candidate SHA.

1. #189 proves the same first-party IdP/BFF/Biz API/MySQL environment and controlled Notification runtime integration. It does **not** claim production email/SMS provider qualification.
2. API_MODE_E2E injected 409/5xx/readback outcomes prove UI behavior and fail-closed semantics. They are labeled as such and are not presented as spontaneous real-runtime failures.
3. Out-of-scope commercial/customer/device work from #116/#117/#131/#133 is not implemented by #189.
4. Final merge/main identity is accepted only from the repository's candidate lifecycle, PR Merge Gate and main verification receipts; screenshots alone are not completion evidence.
