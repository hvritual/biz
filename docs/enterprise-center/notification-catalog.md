## 领域与运行时所有权

| 层次 | 当前源码职责 | 边界 |
| --- | --- | --- |
| Notification domain | 不可变类型/渠道快照、三级优先级、配置值与校验、分页/筛选/回执合同 | 目录级别不是权限或个人偏好豁免 |
| Notification persistence | 配置、渠道/接收人关系、CAS、持久幂等回执、同快照列表 | 借用根事务，不建立第二数据库或 UoW |
| Access directory | 本企业当前有效成员 ID/显示名、当前动作与业务范围事实 | 不暴露原始联系地址/凭据；Notification 不跨域读表 |
| DeviceOps directory | 点位存在性、成员显式范围与策略交集、按需锁定资源 | group 一期适配 site；部门/负责人不隐式授权 |
| Application / generated API | 当前身份、独立动作、引用重验、多等级事务、回执及原子审计 | 同一个 Executor；原生 IAM/Commercial 拒绝保留 |
| Web | 既有 `/system/notifications`、类型与规则表格、受控分页选择、确认及恢复 | 不另建页面树；前端按钮不替代服务端 403 |

固定注册来源为 `internal/bizruntime/notification_configuration.go`。当前类型清单是设备故障、设备通信离线、维护到期、通信恢复、企业系统通知的显式注册；事件生产和投递适配仍属 #185，不因注册名称就宣称已接入事件源。

渠道注册 `in_app`、`sms`、`email`。站内渠道可保存配置；短信、邮件适配器未配置时返回不可配置原因并拒绝新选。**注册、配置成功、供应商受理、实际送达是不同状态**。#184 不提供假成功的启用开关，也不以紧急/重要绕过个人短信/邮件拒绝。

## 查询与写入合同

类型目录按 urgent / important / general 顺序分组，子类型按编码稳定排序。编码/名称按字面子串匹配，与级别以 AND 组合；`%`、`_` 不具有通配符意义。分组计数与总数在同一过滤快照上统计，分页不改变总数。

内部目录要求显式合法页码和页大小；公开 Application 为缺省 page/page_size 映射 1/20，上限 1,000,000/100。前端提交明确页码/页大小并校验回显，目录选择器分页读取，不将前 100 项当作全集。

`nil`/未初始化快照表示目录不可用，显式空集合才是成功空目录。API 错误不转为空表或 demo 数据。

企业规则以 `tenant + site + level` 唯一。第一联系人必填，第二联系人选填且不同人，附加接收人最多 100 个且不与前两者重合；所有候选在本企业仍有效。一次选择多等级按等级产生记录，配置、关系、审计和回执同事务整体成功或回滚。编辑不修改 tenant/site/level，接收人集合整体替换；删除关系与配置同事务。更新、删除要求精确预期版本。

幂等键按可信租户、操作者、操作隔离；同键换请求拒绝，重放返回原回执而不覆盖新状态。写入重新检查当前权限、点位范围和接收人有效性，所需锁持续至根事务结束；不把自动提交模式当作持锁事务。

列表同时应用可信企业、当前可管理点位、级别与接收人过滤。查询总数、分页与关系读取不能观察不同配置快照。Create/Update/Delete 分别校验对应服务端 Action，A 企业不能访问 B 企业对象。

## 页面与恢复

沿用 SettingsView 的 FormPage、Shell、主题 Token、基础控件和对话框。通知页有独立精确路由授权，其他系统设置路由保持原授权要求，不将通知权限添加到全部系统页。

浏览器从已有可信会话捕获企业和用户；请求前后检查会话并校验返回租户，版本以十进制字符串保留 uint64 精度。每次确认冻结原请求内容和幂等键；选中行编辑前权威读取，成功后核对完整字段与精确版本。

| 结果 | 页面行为 | 允许恢复 |
| --- | --- | --- |
| 明确拒绝 | 显示具体业务错误，不显示成功 | 冲突/撤权/对象或渠道失效先刷新；参数错误可修正 |
| 提交结果不明 | 保留不可变原命令，禁止另开写操作 | 原内容与原幂等键重试；不能产生新请求 |
| 已有回执、读回失败 | 显示“已受理、待核对”，不显示已确认 | 只重试读取，不再次写入 |
| 读回发现后续变化 | 保留回执并显示当前状态 | 不把新状态覆盖回旧请求 |
| 切企业/会话变化/卸载 | 清空旧企业快照、对话框、恢复上下文 | 迟到响应丢弃，不跨企业重试 |

取消不写入；无数据、加载中、权限拒绝和服务不可用分别呈现。UI 不以未知数据填零，不显示伪造的企业所有者身份或本地保存结果。
