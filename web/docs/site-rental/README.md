# SR-01 点位租赁与计费范围：界面审核切片

## 已确认的产品决定

本轮依据用户在客户经营设计后确认的“按照建议执行”，落实：固定月租、按杯计费、基础费用含杯数加超量计费；同合同指定点位可选择独立核算或共享额度。沿用原 CoffeeLink 组件与页面规范，点位为履约/数据单位，客户为经营单位，设备为可替换资产。不扩展通用设备与订单管理。

业务含杯额度与商业权益/SaaS 套餐配额是不同对象；不能复用 commercial-entitlements 的配额计数器。

## 本轮基线与边界

上轮指定基线 `911ab19122ec009de8028fdc4b293b1358127be1` 的客户经营实现位于 `feat/coffeelink-customer-ui`。实施前回读该分支已新增用户的“调整布局”提交 `04dedc3826e23754f0cffa13ed5c27b5c4224071`。本轮从该提交建立独立分支，不覆盖这次布局调整，不合并 main 或上轮 Draft PR #40。

本轮交付原生 Vue 界面与本地交互：点位列表/详情/建档、既有投放履历、运营停用及恢复、关联同一客户事项、三种算法与保底子类型、独立/共享范围、无副作用试算、规则草稿与未来版本发布、对账草稿/异议/核对/冻结。新页面均明确标记示例数据。

**不宣称完成生产计费系统。** 当前未实现后端鉴权、实际设备换机/撤场、用量采集/补传、正式应收/发票/扣款、财务核销、自动通知、合同审批、真实跨租户共享或账单调整接口。

## 模型与来源

- `CustomerSnapshot.rental`：现有租户隔离快照的可选扩展，不创建第二套客户库或任务表。旧快照无此扩展时按明确示例初始化。
- `profiles`：点位主档。既有 SITE-041/042/043 沿用原交付点位 ID；原 `snapshot.sites` 仍为交付验收事件投影，不是第二个可编辑主档。SITE-044/045 是本轮显式示例明细，用于展示月租与按杯模式，不代表真实部署数量。
- `deployments`：独立记录设备、点位、开始/结束日期；时间区间为 `[from, until)`，历史关系不授予后续数据权限。
- `rules`：同客户同合同的版本化计费组；`siteIds` 随规则版本一起保留，拒绝与其他组的重叠计费区间。
- `usage`：按点位/账期的只读示例用量快照，原始/排除/可计费分开。示例 `2026-09` 使用标明时间的月末场景快照，不冒充当前实时用量或未来预测。
- `statements`：核对快照，不是正式应收；确认后不允许刷新覆盖。
- 点位事项写入现有 `snapshot.work`，通过 `siteIds` 关联；点位、客户和事项工作台看到同一记录。

## 计算口径

金额以整数分计算；人民币，自然月，展示时区 Asia/Shanghai。

1. 固定月租：完整账期租金 × 收费单位数量。单位明确为点位或在租设备。遥测缺失不自动免除固定租金。
2. 按杯计费：可计费杯数 × 单价。排除口径来自合同，本示例排除测试制作，不能推广为所有合同默认规则。
3. 基础费用含杯数：基础费用 + max(可计费杯数 - 含杯数, 0) × 超量单价。
4. 第三模式的“最低消费金额”子类型明确使用 max(最低消费, 可计费杯数 × 单价)，不能与含杯数算法混同。

共享模式先汇总组内用量，只收一次基础费、只扣减一次整组额度。例：600 + 1300 = 1900 杯，整组 2000 杯，剩余 100 杯；不能按每点 1000 杯推导第二点超量 300 杯。各点位显示贡献，不生成点位独立应收。选择“各点位独立计算”时额度和基础费明确逐点适用；账单客户汇总不改变这一核算方式。

缺失/待补传不是零：按杯与保底模式金额显示缺失并阻断确认。真实零杯可依合同算出零费用或基础费。停用运营不自动停租、不改额度、不终止投放或共享；对账要显式核对费用约定。

## 本轮对尚未确认条款的处理

仅允许完整自然月和未来月初的规则发布；月中起租、费用折算、计费模式中途切换、税费/优惠、多个币种及复杂阶梯单价没有凭空设定默认算法。检测投放覆盖缺口或按设备计费的月内数量变化时阻断确认，提示核对约定。连续换机、收费数量不变不会重复计租。已确认快照后到数据通过后续调整模块处理，本轮不提供伪造的调整成功按钮。

规则发布不会跨合同改绑；续约应以新合同建立新计费范围并明确边界。当前关联来源仍为现有客户模块的示例合同，不是合同有效性的生产证明。到期合同不参与后续账期的规则选择，不遮挡续约计费组；历史账期和已确认快照仍保留原规则。按点位独立计算时，点位首屏只展示该点位分项金额，不把整组汇总额重复放到每个点位。

## 页面与动作映射

| 入口 | 页面/动作 | 闭环 |
|---|---|---|
| `/#/sites` | 点位列表、筛选、建档 | 输入→重复/归属校验→保存→详情回读；分组不可计费 |
| `/#/sites/:id` | 点位概览 | 责任人、现场条件、当前服务、下一步行动 |
| `?tab=placements` | 投放履历 | 当前/历史关系、起止、角色、数据范围说明 |
| `?tab=rental` | 租约与结算 | 生效规则→用量贡献/费用→对账入口 |
| `?tab=usage` | 使用数据 | 原始/排除/计费杯数、完整性和时间来源 |
| `?tab=service` | 服务与事项 | 点位创建→既有客户事项→单一状态回读 |
| `/#/sites/groups` | 规则与共享组 | 列表/草稿/预约版本，三种模式独立呈现 |
| `/#/sites/groups/:groupId` | 计费组详情 | 范围→试算→变更预览→发布→版本履历 |
| `/#/sites/statements` | 对账台账 | 草稿→异议→结论→核对→冻结；禁止重复生成 |

## 组件复用与代码组织

AppShell、AppHeader、PrimaryNavigation、ModulePanel、公共 UI 组件、原 tokens.css/base.css 均保持基线内容。只扩展导航配置和路由。旧浏览器测试中已经过时的绝对 x/width 断言改为当前一级栏几何与展开前后的一致性断言；仍校验 480px、零缝隙、不推挤、折叠可用和 Escape 关闭。

- `types/siteRental.ts`：领域类型。
- `services/siteRental/`：规则校验、整数计价、示例与选择器、命令。
- `components/siteRental/`：点位表单、规则编辑、核算详情、对账对话框。
- `views/siteRental/`：页面组合、筛选、详情与路由状态。
- `stores/customer.ts`：复用原持久化边界，写成功后才更新内存；版本冲突保留草稿。
